quick start
$ chmod +x stellar
$ ./stellar hello.ste             # compile & run
$ ./stellar hello.ste --quiet     # compile only
$ ./stellar hello.exe             # run bytecode
$ ./stellar hello.ste -o hello.exe --encrypt mykey  # encrypt output
