Language Design

Built for clarity,
Built for you.

01
Explicit Numeric Types
Two types, zero ambiguity. int for integers, let for double-precision floats. You always know what you're working with.
02
Deterministic Execution
Same input, same output, every time. No runtime surprises, no non-deterministic GC pauses.
03
Structured Control Flow
Clean if/else and while with proper scoping.
04
Manual Memory
Arrays are explicitly sized. No hidden heap activity. You declare it, you own it.
05
Compact VM Target
Compiles to a tight bytecode format. Runs on the Stellar VM — small, fast, embeddable.
06
Binary Encryption
Obfuscate compiled binaries with --encrypt <key>. No key, no execution.
Example

Sieve of Eratosthenes

primes.ste
// Mark composites up to 100000
int is_prime = [100001];
int i = 2;

while (i < 100001) {
    int status = is_prime[i];
    if (status == 0) {
        int j = i;
        j *= 2;
        while (j < 100001) {
            is_prime[j] = 1;
            j += i;
        }
    }
    i++;
}

print("done.");
