Introduction

Getting Started with Nova

Nova is a compiled, statically typed language that uses LLVM as its backend, linking with clang to produce native executables. The syntax is familiar — if you've written C, C++, or Java, you'll feel at home immediately.

Download the compiler from source using the downloads page.

If you have an GUI, right click on the tar.gz file -> Extract Here. If you have not, run

terminal
tar -xzvf nova-lang-v1.2.0beta.tar.gz

Open the terminal on the extracted folder and run

terminal
chmod +x install.sh
terminal
sudo ./install.sh

After it sucessfully installs the language, restart the terminal, and start coding!

Hello, World

Create a file named hello.npp:

hello.npp
#include <stdio.nh>

void main() {
    std::printf("Hello, World!\n");
}

Compile and run:

terminal
$ ./n++ hello.npp
$ ./hello
Hello, World!

Program Structure

A Nova program is a flat list of top-level declarations — global variables, global arrays, and function definitions. Execution starts at main.

Functions must be declared before they are called. Declare helper functions above their callers.
Types

Data Types

Nova has seven primitive types. All types are checked at compile time — there are no implicit conversions.

Variables

Variables

Variables require an explicit type at declaration. They can be optionally initialized; uninitialized variables default to 0 or null.

int x;
int y = 10;
float pi = 3.14;
string name = "Nova";

Assignment

Basic and compound assignment operators are all supported:

x = 42;
x += 5;   // x = x + 5
x -= 3;   // x = x - 3
x *= 2;   // x = x * 2
x /= 4;   // x = x / 4
x++;      // x = x + 1
x--;      // x = x - 1

Scope

Variables declared outside functions are global and accessible anywhere. Variables declared inside a function or block are local and destroyed when the block ends.

Operators

Operators

Arithmetic & Comparison

OperatorMeaning
+ - * /Arithmetic: add, subtract, multiply, divide
%Modulo (integer remainder) — integers only
== !=Equal, not equal
< > <= >=Comparison
&& ||Logical AND / OR (short-circuit)
!Logical NOT

Precedence

From highest to lowest: ! → * / % → + - → comparisons → && → ||. Use parentheses to override.

&& and || use short-circuit evaluation — the right side is not evaluated if the result is already determined by the left side.
Control Flow

Control Flow

Nova requires the then keyword before the body of an if statement.

if(x > 0) then {
    std::printf("positive\n");
} else if(x == 0) then {
    std::printf("zero\n");
} else {
    std::printf("negative\n");
}

You can chain as many else if branches as needed. The final else is optional.

Loops

Loops

while

int i = 0;
while(i < 10) {
    std::printf("%d\n", i);
    i++;
}

for

Classic three-part syntax: initializer, condition, step. The loop variable can be declared inside the for or already exist.

for(int i = 0; i < 10; i++) {
    std::printf("%d\n", i);
}

// step can be any assignment
for(int i = 0; i < 100; i += 5) {
    std::printf("%d\n", i);
}
Functions

Functions

Functions are declared with a return type, name, and typed parameter list. They support full recursion.

#include <stdio.nh>

int add(int a, int b) {
    return a + b;
}

int factorial(int n) {
    if(n <= 1) then { return 1; }
    return n * factorial(n - 1);
}

void Functions

Functions that produce side effects but return no value use void. The return; statement is optional at the end.

#include <stdio.nh>

void greet(string name) {
    std::printf("Hello, %s\n", name);
}

void main() {
    greet("world");
}

Calling Functions

Functions can be called as expressions (capturing the return value) or as statements (discarding it):

int result = add(3, 4);   // capture return
add(10, 20);                // discard return
greet("Nova");             // void call

Struct Support in Functions

As of version 1.3.0, functions can accept structs as arguments and return structs. The compiler automatically manages the stack memory layout for copying these structures.

struct MyStruct {
    int x;
    int y;
}

MyStruct calculate_point(MyStruct a, MyStruct b) {
    MyStruct c;
    c.x = a.x + b.x;
    c.y = a.y + b.y;
    return c;
}
Arrays

Arrays

Arrays have a fixed size specified as an integer literal at declaration time. They can be stack-allocated (local) or global.

int nums[10];                          // zeroed
int primes[5] = {2, 3, 5, 7, 11};   // initialized
float coords[3] = {1.0, 2.5, 3.0};

int x = primes[0];        // read → 2
primes[2] = 99;           // write
primes[i + 1] = x;       // expression index
Nova performs compile-time bounds checking for literal indices (e.g. arr[10] on a size-5 array is a compile error). Dynamic indices (arr[i]) are not checked at runtime.

Arrays of Structs

As of version 1.3.0, you can create arrays of user-defined struct types. The compiler correctly calculates the memory offsets for accessing fields within the array elements.

struct Point {
    int x;
    int y;
}

void main() {
    Point arr[5];
    arr[0].x = 10;
    arr[0].y = 20;
    std::printf("%d\n", arr[0].x);
}
Structs

Structs

Structs let you group related data into a named type. Struct names must start with an uppercase letter.

#include <stdio.nh>

struct Point {
    int x;
    int y;
}

void main() {
    Point p;
    p.x = 3;
    p.y = 4;
    std::printf("%d\n", p.x);   // 3
}

Methods

Functions can be defined inside a struct. Inside a method, all fields are accessible directly by name. Field changes are written back to the instance automatically.

#include <stdio.nh>

struct Counter {
    int value;

    void increment(int n) {
        value = value + n;
    }

    int get() {
        return value;
    }
}

void main() {
    Counter c;
    c.value = 0;
    c.increment(5);
    std::printf("%d\n", c.get());   // 5
}
Struct fields support all primitive types: int, long, float, double, char, string. Nested structs are not yet supported.
Types

Explicit Casts

Use C-style casts to convert between types. The compiler warns when precision is lost.

int a = 7;
double d = (double)a / 2.0;   // → 3.5

double pi = 3.14159;
int truncated = (int)pi;       // → 3

int small = 1000000;
long big = (long)small * 1000000;

char ch = 'A';
int code = (int)ch;             // → 65
Type Safety

Type Safety

Nova enforces strict type rules at compile time. There are no implicit conversions between numeric types — explicit casts are required.

No implicit int ↔ float conversion

Arithmetic between int and float is a compile error. Both sides must be the same type.

float x = 3.14;
int   n = 2;
// float r = x * n;    ← ERROR: cannot mix float and int
float r = x * 2.0;   // OK

Literal type must match declaration

Initializing a float variable with an integer literal is an error — the compiler suggests the fix.

// float radius = 2;     ← ERROR: use 2.0
float radius = 2.0;  // OK

Compile-time array bounds checking

Accessing an array with a literal index that is out of range is caught at compile time.

int arr[5];
// arr[10] = 1;   ← ERROR: index 10 out of bounds (valid: 0..4)
arr[4] = 1;        // OK
arr[i] = 1;        // OK — dynamic index not checked
Standard Library

Standard Library

Nova ships with a standard library under /usr/local/lib/nova/. Headers are included with #include <name.nh>. The compiler automatically finds and compiles the corresponding .npp implementation alongside your code.

All stdlib functions live under a namespace. Use the namespace:: prefix to call them — e.g. std::printf(...).
Standard Library

stdio — printf & print

Include <stdio.nh> to get std::printf for formatted output and std::print for quick single-value output. Both are implemented without libc — they use the write syscall directly.

hello.npp
#include <stdio.nh>

void main() {
    std::printf("Hello, %s!\n", "World");
    std::printf("int: %d  long: %ld  double: %f\n", 42, 9876543210, 3.14);
    std::printf("char: %c  str: %s\n", 'A', "nova");
}

std::print — type-overloaded shorthand

std::print prints a value followed by a newline. The correct overload is selected automatically based on the argument type.

#include <stdio.nh>

void main() {
    std::print(42);           // int
    std::print(3.14);         // double
    std::print("hello");      // string
    std::print('Z');          // char
    std::print(9876543210);  // long (auto-promoted)
}
Standard Library

math — sqrt

Include <math.nh> for mathematical functions. std::sqrt is overloaded for int, float, and double.

#include <stdio.nh>
#include <math.nh>

void main() {
    std::printf("%f\n", std::sqrt(2));    // int overload → 1.414214
    std::printf("%f\n", std::sqrt(9.0));  // double overload → 3.000000
}
Standard Library

Namespaces

Header files (.nh) declare a namespace with the namespace keyword. All functions declared after it belong to that namespace and must be called with the namespace:: prefix.

mylib.nh
namespace math;

int add(int a, int b);
double square(double x);
main.npp
#include <stdio.nh>
#include "mylib.nh"

void main() {
    std::printf("%d\n", math::add(3, 4));
}
Calling a namespace function without the correct prefix — or without the corresponding #include — is a compile-time error.
Beta 1.3.0 Breaking Change: The use of namespaces defined in header files (.nh) is now strictly mandatory for accessing structs and functions bound to them.
Functions

Function Overloading

Multiple functions can share the same name as long as their parameter types differ. The compiler resolves the correct version at call time based on the argument types.

#include <stdio.nh>

int square(int x)    { return x * x; }
double square(double x) { return x * x; }

void main() {
    std::printf("%d\n",   square(5));     // → 25 (int)
    std::printf("%f\n", square(2.5));   // → 6.250000 (double)
}
Headers

Header Files (.nh)

A .nh file declares the public interface of a Nova library — function signatures, struct definitions, and global constants. It contains no function bodies. The corresponding .npp file provides the implementations.

When you write #include <name.nh> (for standard libraries) or #include "name.nh" (for local libraries), the compiler reads the header, registers all declarations, but passing the .npp file to the compiler is required.

Anatomy of a header

geometry.nh
// geometry.nh — public interface for the geometry library

namespace geo;

// Struct declarations are allowed in headers
struct Point {
    double x;
    double y;
}

// Function signatures — type + name + params + semicolon, no body
double distance(double x1, double y1, double x2, double y2);
double area(double base, double height);
int    sign(int n);
geometry.npp
#include <stdio.nh>
#include <math.nh>

double distance(double x1, double y1, double x2, double y2) {
    double dx = x2 - x1;
    double dy = y2 - y1;
    return std::sqrt(dx * dx + dy * dy);
}

double area(double base, double height) {
    return base * height / 2.0;
}

int sign(int n) {
    if(n > 0) then { return 1; }
    if(n < 0) then { return 0 - 1; }
    return 0;
}
main.npp
#include <stdio.nh>
#include "geometry.nh"

void main() {
    double d = geo::distance(0.0, 0.0, 3.0, 4.0);
    std::printf("distance = %f
", d);   // 5.000000

    double a = geo::area(6.0, 4.0);
    std::printf("area = %f
", a);       // 12.000000
}

Headers

Best Practices

Always declare a namespace in every .nh file

A namespace makes it explicit where a function comes from and prevents name collisions when multiple libraries are combined. Without one, all names land in the global scope and can silently shadow each other.

// ✗ Avoid — names pollute global scope, collisions are silent
int clamp(int v, int lo, int hi);
double lerp(double a, double b, double t);

// ✓ Prefer — origin is clear, call site is unambiguous
namespace math;
int clamp(int v, int lo, int hi);
double lerp(double a, double b, double t);

With a namespace, call sites become self-documenting — math::clamp(x, 0, 100) is immediately obvious in a way that bare clamp(x, 0, 100) never is.

Declare functions above their callers

Nova resolves names top-to-bottom within a file. If function B calls function A, define A first. For mutual recursion between two files, use a header to forward-declare one of them.

Use overloading instead of name suffixes

Instead of sqrtInt, sqrtFloat, sqrtDouble, define one function name with different parameter types. The compiler picks the correct version automatically — and callers don't need to care about the underlying type.

// ✗ Avoid
int    absInt(int n)       { return n < 0 ? 0 - n : n; }
double absDouble(double n) { return n < 0.0 ? 0.0 - n : n; }

// ✓ Prefer
int    abs(int n)    { return n < 0 ? 0 - n : n; }
double abs(double n) { return n < 0.0 ? 0.0 - n : n; }

Use long for large integers

int holds values up to 2,147,483,647. For counters, byte offsets, or values that can exceed that range, use long. Integer literals larger than INT_MAX are automatically promoted to long by the compiler — but when doing arithmetic that could overflow, cast explicitly before the operation.

// ✗ Overflow — arithmetic done in int, widened too late
long bad  = 1000000 * 1000000;

// ✓ Correct — cast before the multiplication
long good = (long)1000000 * 1000000;

// ✓ Auto-promoted — literal exceeds INT_MAX
long size = 9876543210;

Prefer double over float for precision

double gives 15–16 significant digits; float gives only 6–7. Use float only when you specifically need 32-bit representation — for example, when interfacing with hardware or external binary formats that require it.

One concern per .npp file

Keep each .npp focused on a single topic — strings, geometry, IO. Pair it with a .nh that exposes only what callers need and hides internal helpers. This makes each module independently testable and easy to reuse across projects.

Interactive Editor (-w)

Nova ships with a built-in terminal editor. Launch it with -w, optionally passing a file to open.

terminal
$ n++ -w                  # new file (prompts for name)
$ n++ -w myfile.npp       # open existing file

The editor highlights keywords, types, numbers, strings, and comments in real time. An unsaved changes indicator (●) appears in the status bar.
Examples

Full Examples

Fibonacci

fib.npp
#include <stdio.nh>

int fib(int n) {
    if(n <= 1) then { return n; }
    return fib(n - 1) + fib(n - 2);
}

void main() {
    for(int i = 0; i <= 10; i++) {
        std::printf("%d\n", fib(i));
    }
}

Sieve of Eratosthenes

sieve.npp
#include <stdio.nh>

int limit = 100000;
int isPrime[100001];

void main() {
    for(int i = 2; i <= limit; i++) {
        if(isPrime[i] == 0) then {
            int j = i * 2;
            while(j <= limit) {
                isPrime[j] = 1;
                j += i;
            }
        }
    }
    for(int n = 2; n <= limit; n++) {
        if(isPrime[n] == 0) then {
            std::printf("%d\n", n);
        }
    }
}

FizzBuzz

fizzbuzz.npp
#include <stdio.nh>

void main() {
    for(int i = 1; i <= 100; i++) {
        if(i % 15 == 0) then {
            std::printf("FizzBuzz\n");
        } else if(i % 3 == 0) then {
            std::printf("Fizz\n");
        } else if(i % 5 == 0) then {
            std::printf("Buzz\n");
        } else {
            std::printf("%d\n", i);
        }
    }
}

Struct with Methods

rectangle.npp
#include <stdio.nh>

struct Rectangle {
    int width;
    int height;

    int area() {
        return width * height;
    }

    int perimeter() {
        return (width + height) * 2;
    }
}

void main() {
    Rectangle r;
    r.width = 6;
    r.height = 4;
    std::printf("area=%d\n", r.area());        // 24
    std::printf("perimeter=%d\n", r.perimeter());  // 20
}
